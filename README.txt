FORGE FITNESS GYM DEMO — GitHub + Vercel

1. Extract this ZIP.
2. Upload index.html to the root of a new GitHub repository.
3. In Vercel, choose Add New > Project and import that repository.
4. This is a static HTML website. Choose Framework Preset: Other.
5. Leave Build Command empty and Output Directory empty/default, then deploy.

Before publishing for a real gym, replace the sample gym details, prices, reviews, and placeholder WhatsApp number (910000000000) inside index.html.
